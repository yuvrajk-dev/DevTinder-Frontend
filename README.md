# DevTinder — Frontend

Frontend for **DevTinder**, a developer networking platform built to help developers discover and connect with each other.

## 🚧 Status

Currently under development.

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript

## 🔗 Backend

DevTinder uses a separate **Node.js + Express + MongoDB/Mongoose** backend with authentication, user profiles, and connection request functionality.

## ▶️ Run Locally

```bash
npm install
npm run dev
```
