# 💻 DevTinder – Developer Networking Platform

![React](https://img.shields.io/badge/React-19-blue)
![Redux Toolkit](https://img.shields.io/badge/Redux-Toolkit-purple)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-CSS-38BDF8)
![DaisyUI](https://img.shields.io/badge/DaisyUI-UI%20Components-purple)
![Vercel](https://img.shields.io/badge/Deployed-Vercel-black)

A Tinder-inspired networking platform built for **developers** to discover, connect, and collaborate with other developers. DevTinder allows users to create profiles, explore other developers, send connection requests, and build meaningful professional connections.

🔗 **Live Demo:** https://devtinder-social.vercel.app

---

## ✨ Features

* 🔐 User authentication with signup and login
* 👤 Create and manage developer profiles
* 🔍 Discover other developers through a swipe-style interface
* ❤️ Send connection requests to developers
* ❌ Ignore profiles you're not interested in
* 🤝 Accept or reject incoming connection requests
* 👥 View your developer connections
* 🔒 Protected routes for authenticated users
* ⚡ Global state management using Redux Toolkit
* 📱 Fully responsive design across desktop, tablet, and mobile
* 🎨 Modern UI built with Tailwind CSS and DaisyUI

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yuvrajk-dev/YOUR-FRONTEND-REPO.git
cd YOUR-FRONTEND-REPO
```

### Install dependencies

```bash
npm install
```

### Create a `.env` file

```env
VITE_BASE_URL=your_backend_api_url
```

### Start the development server

```bash
npm run dev
```
